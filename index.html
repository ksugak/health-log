    기록 내보내기

    AI 숫자 읽기

    키는 이 기기에만 저장되고, 사진의 숫자를 읽을 때 사진과 함께 Anthropic으로만 전송돼요. 읽을 때마다 소액의 API 요금이 들어요.

    사용 방법

    📷 찍어서 기록
    혈압계나 체중계 화면을 찍으면 사진이 뜨고, 사진을 보면서 숫자를 입력해 저장해요. 사진은 기록과 함께 남아요.
    ⌨️ 직접 입력
    사진 없이 숫자만 적을 수도 있어요. 측정 시각을 바꿔 지난 기록도 넣을 수 있어요.
    🩺 정상 여부 안내
    기록하면 성인 기준으로 정상·주의·높음·고위험 중 어디인지 알려 줘요. 체중은 “설정”에 키를 넣어야 판정돼요. 참고용이며 진단이 아니에요.
    💊 혈압약 확인
    혈압을 기록하면 혈압약을 먹었는지 물어봐요. “먹었어요”라고 답하면 그날은 다시 묻지 않아요. 약을 먹지 않는 분은 “설정”에서 끌 수 있어요.
    📈 추이 보기
    30일·90일 그래프로 변화를 볼 수 있어요. 그래프를 누르면 그날의 숫자가 보여요.
    🗂 기록 확인·삭제
    아래 기록 목록에서 항목을 누르면 사진을 크게 보고 삭제할 수 있어요.
    📄 병원에 보여주기
    “설정”의 “CSV 파일로 저장”으로 전체 기록을 표 파일로 내보낼 수 있어요.
    🤖 AI 숫자 읽기 (선택)
    “설정”에 Anthropic API 키를 넣으면 사진 속 숫자를 AI가 읽어 채워 줘요. 저장하기 전에 숫자가 맞는지 꼭 확인하세요.
    🔒 내 기록은 내 폰에만
    기록과 사진은 이 기기에만 저장돼요. 앱이나 브라우저 데이터를 지우면 함께 사라지니 가끔 내보내 두세요.
